# 《伞下》中文故事脚本文件说明

## 概述
根据 `new.txt` 中的中文故事内容，已将故事改写为 WebGAL 脚本格式，使用项目现有的美术素材（背景图片、音乐、人物头像等）。

## 创建的文件

### 1. `start_umbrella_cn.txt` (入口文件)
- **用途**: 中文故事的启动文件
- **功能**: 
  - 初始化所有游戏变量（线索计数、理智值、共鸣值等）
  - 显示游戏标题《伞下》
  - 加载开场音乐和背景
  - 跳转到序章文件

**如何使用**: 将游戏启动文件更改为此文件，即可启动中文故事

### 2. `umbrella_prologue_cn.txt` (序章文件)
- **标题**: 序章 · 黑水
- **内容范围**: 整个序章内容 (对应 new.txt 的序章部分)
- **功能**: 
  - 展示初苓和湖边神秘女孩的梦境场景
  - 初苓在医院的苏醒
  - 与母亲、医生、警察的交互
  - 出院回到学校
  - 包含一个重要选择：是否打开同学座位上的便签

### 3. `umbrella_chapter1_cn.txt` (第一章文件)
- **标题**: 第一章 · 裂缝
- **内容范围**: new.txt 的第一章部分
- **功能**:
  - 描述初苓的梦境延续与醒来后的宿舍、洗漱、课堂、画室经历
  - 包含“是否进入美术室”的关键选择
  - 创建了线索、回忆与分支发展

### 4. `umbrella_chapter2_cn.txt` (第二章文件)
- **标题**: 第二章 · 碎片
- **内容范围**: new.txt 的第二章开始内容
- **功能**:
  - 展示初苓在湖中梦境与美术教室中的碎片回忆
  - 引入小雪日记与“数到五”的记忆碎片
  - 目前以“未完待续”处理第二章结尾

## 故事追踪变量

脚本使用以下变量跟踪故事进度：
- `clue` - 收集到的线索数量
- `trace` - 发现的现实痕迹
- `empathy` - 共鸣/同情心值
- `lucid` - 清醒梦依赖程度
- `sanity` - 理智值
- `avoid` - 逃避行为
- `injury` - 受伤程度
- `guilt` - 罪恶感

这些变量将影响故事的后续分支和结局。

## WebGAL 脚本格式说明

### 常用命令
```
; 注释
changeBg:file.JPG -next;  # 切换背景
bgm:file.mp3 -volume=55;  # 播放背景音乐
miniAvatar:file.png;      # 设置迷你头像
changeFigure:file.png;    # 设置人物立绘
Chuling:对话文本;         # 人物说话
:描述文本;                # 叙述文本
playEffect:file.mp3;      # 播放音效
setVar:var=var+1;         # 修改变量
choose:选项1:label1|选项2:label2;  # 选择分支
label:label_name;         # 标签定义
jumpLabel:label_name;     # 跳转标签
changeScene:file.txt;     # 切换场景
intro:文本;               # 过场文字
```

## 扩展建议

### 后续章节
目前脚本已包含完整的序章内容，并已继续扩展到第一章和第二章。要继续故事：
1. 创建或扩展 `umbrella_chapter3_cn.txt` 文件
2. 将 new.txt 中后续章节部分转换为 WebGAL 脚本
3. 在 `umbrella_chapter2_cn.txt` 的最后添加跳转命令

### 美术资源
如需要更多背景图片或人物立绘，可以：
1. 添加到 `/game/background/` 或 `/game/stand/` 目录
2. 在脚本中使用 `changeBg:` 或 `changeFigure:` 命令引用

### 音乐和音效
新增音频文件应放在 `/game/bgm/` 或 `/game/audio/` 目录中。

## 故事特色

- **记忆碎片叙事**: 初苓因失忆而逐步拼凑真相
- **多重分支**: 玩家的选择会影响故事进展和人物关系
- **心理状态追踪**: 通过变量系统反映初苓的精神状态变化
- **神秘氛围**: 湖边的秘密、空座位、紫色伞等元素构建悬念

## 注意事项

1. 所有中文脚本使用 UTF-8 编码
2. 变量名和命令必须为英文
3. 人物对话和描述文本使用中文
4. 音频文件路径相对于 `/game/` 目录
5. 建议定期保存工作内容
